Prompt for Replit Agent — Automat-IA Diagnostic Webapp (MVP, corrected) Mission Build a webapp that lets Automat-IA manage Phase-1 diagnostics per project (company) and workflow. Admin creates workflows and personalized Technical Feasibility Assessments (TFA), sends a shareable link to the respondent, captures results, prefills the Readiness Rubric (editable), and lets admin enter ROI calculator outputs. Only when TFA + Readiness + ROI are present does the app place the workflow on the Opportunity Matrix (per company) and track which implementations are done. Core UX 1) Home (Projects) List of Projects (Companies) with: company name, #workflows, last updated. Click a project → Project Dashboard. 2) Project Dashboard Header: Company name. Workflows table: title, department, Feasibility score, Readiness score, ROI status, Matrix quadrant, Implementation status (Not started / Proposed / In progress / Implemented). Button “New Workflow” (admin fills): Workflow Title (admin) Department (select/text) Short Description (admin) Each workflow row has actions: Create/Manage TFA Link View TFA Responses Readiness Rubric (prefilled & editable) Enter ROI Outputs Matrix View (company-specific) 3) Technical Feasibility Assessment (TFA) Admin creates a personalized TFA link after filling: Respondent Name, Role, Email (admin) App generates shareable URL (signed token + expiry). Public TFA form (client-facing): Closed-ended questions + weights from attached rubric doc. On submit → Thank you screen (no scores shown). Server auto-scores total + sub-scores, stores response, and prefills the Readiness Rubric fields that map to tech dimensions (System Access, Data Quality, Integration Feasibility). (These appear in Readiness as prefilled but editable.) 4) Readiness Rubric (Admin-only) Page shows six dimensions with inputs: Prefilled from TFA (editable): System Access, Data Quality/Availability, Integration Feasibility. Admin-entered: Process Clarity, Change Magnitude, Workflow Brittleness. These are likert type questions. Namely: Process Clarity: How standardized and repetitive is the current process? 1=Highly variable - Each case is handled differently. 4=Strict standards - Detailed rules and quality requirements When you perform this process, do you always follow the same sequence of steps? 1=Steps vary each time, 5=Always the same steps Are instructions, templates, or reference materials easily available when you need to perform this task? 1=None, 5=Always available and up to date Change magnitude: How often do the rules or requirements for this workflow change? (inverse scoring)1 = Weekly … 5 = Rarely or never How much do you think your daily work would change if parts of this process were automated? 1 = Completely different … 5 = Almost no change How comfortable do you feel adopting new tools or digital solutions at work?1 = Very uncomfortable … 5 = Very comfortable Workflow brittleness: How often do errors, missing data, or inconsistencies occur during this process? (inverse scoring)1 = Very often … 5 = Rarely How dependent is this workflow on manual workarounds (Excel files, copy-paste, rework)? (inverse scoring)1 = Extremely dependent … 5 = Fully automated or structured If something goes wrong, is there a clear way to detect and fix the issue quickly?1 = No process / takes long … 5 = Clear and efficient correction process . How consistent are the inputs or requests you receive for this process?1 = Always different … 5 = Very consistent and predictable Save computes Readiness Score (0–100) (weights editable in Settings). 5) ROI Inputs (Admin-only) Form to record raw ROI calculator outputs exactly as I provide (no business logic hardcoded here). Store raw fields and show “ROI: Complete/Incomplete”. The logic for how the calculator works is attached in Automat-IA roi calc company handbook document. 6) Opportunity Matrix (per Company) When a workflow has TFA + Readiness + ROI: Compute Effort Index from Feasibility & Readiness (formula configurable). Compute Impact using ROI outputs Place workflow on company-specific matrix with quadrants. Logic for placement has to be based on the provided data on the TFA, readiness rubric and ROI calculator outputs: Quick Wins (Low Effort, High Impact) ⭐ Strategic Vision (High Effort, High Impact) 🚀 Nice-to-Haves (Low Effort, Low Impact) 👍 Deprioritize (High Effort, Low Impact) 🗑️ Matrix page shows all workflows for this company, color by Implementation status, with filter chips (Proposed / In progress / Implemented). Scoring & Config TFA Scoring: Use questions, inversions, and weights from the Word doc: Readiness Scoring (default weights, editable): Process Clarity 20% System Access 15% Data Quality/Availability 20% Integration Feasibility 15% Change Magnitude 15% Workflow Brittleness 15% Effort Index (configurable): Default: Effort = 100 − AVG(FeasibilityScore, ReadinessScore) Impact Score: Quadrant rules: configurable thresholds Data Model (minimum) Project(id, name, createdAt) Workflow(id, projectId, title, department, description, status) Respondent(id, name, role, email) TFAResponse(id, workflowId, respondentId, answersJson, subScoresJson, totalScore, band, createdAt) Readiness(id, workflowId, scoresJson, totalScore, createdAt, updatedAt) ROIResult(id, workflowId, rawJson, impactScore, createdAt, updatedAt) MatrixSnapshot(id, projectId, itemsJson, createdAt) // optional export/history Settings(id, feasibilityWeightsJson, readinessWeightsJson, effortFormula, quadrantConfigJson, roiImpactConfigJson) Endpoints (minimum) POST /api/projects ; GET /api/projects POST /api/workflows ; GET /api/workflows?projectId=… POST /api/respondents POST /api/tfa/link (returns signed URL with respondent + workflow context) GET /api/tfa/form?token=… (serves question set and context) POST /api/tfa/submit (scores, stores, prefills readiness fields) GET /api/workflow/:id/summary → {feasibility, readiness, roi, effort, impact, quadrant} POST /api/readiness (admin) POST /api/roi (admin) GET /api/matrix?projectId=… UI Details Thank-you page after public TFA submit; no results shown to respondent. Admin Readiness page shows prefilled fields from TFA with “edited” badge when modified. ROI page mirrors the fields in my ROI UI (see screenshots); store raw numbers verbatim. Matrix page: grid scatter plot + table below; toggle “Show Implemented”. Acceptance Criteria Admin creates project, creates workflow, enters respondent info, generates sharable TFA link. Respondent completes TFA → app stores response, auto-scores, prefills Readiness tech fields (editable). Admin completes Readiness and inputs ROI outputs. Workflow is automatically ranked and positioned on the company’s Opportunity Matrix only when all three data blocks are present. Dashboard shows per-workflow: Feasibility, Readiness, ROI status, Effort, Impact, Quadrant, Implementation status. All weights/thresholds/formulas live in Settings and are changeable without code changes. Tech (suggested) Backend: Node/Express (or FastAPI) DB: SQLite (+ migration-ready ORM) Frontend: React (Vite) Auth: simple admin password; public TFA protected by signed link token with expiry.
