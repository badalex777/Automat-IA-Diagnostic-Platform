You are integrating with an ROI calculator. Use this specification to ensure your calculations match exactly. Pay close attention to:
1. The order of operations in formulas
2. Capping/bounding rules for percentages
3. How scenario multipliers are applied
4. The difference between Year 1 Actual ROI (with ramp-up) and Annual Run-Rate ROI (steady-state)
If your outputs don't match, check: (1) Are you applying scenario multipliers correctly? (2) Are you capping percentages within bounds? (3) Are you using the correct ramp-up formula?

3. CORE CALCULATION FORMULAS
Step 1: Effective Hourly Rate
effectiveHourlyRate = (averageAnnualSalary / annualWorkingHours) * overheadMultiplier

Example: (55000 / 1920) * 1.2 = $34.375/hour

Step 2: Time Savings Benefits
totalHoursPerWeek = employees * hoursPerWeekPerEmployee
adjustedTimeSavingsPercent = MIN(percentTimeSaved * scenario.timeSavingsMultiplier, 100)
hoursSavedWeekly = totalHoursPerWeek * (adjustedTimeSavingsPercent / 100)
timeSavingsAnnual = hoursSavedWeekly * 52 * effectiveHourlyRate

Example (Base scenario):

totalHoursPerWeek = 3 * 20 = 60 hours
adjustedTimeSavingsPercent = MIN(60 * 1.0, 100) = 60%
hoursSavedWeekly = 60 * 0.60 = 36 hours
timeSavingsAnnual = 36 * 52 * $34.375 = $64,350
Step 3: Quality Impact Benefits
If calculationMethod = "manual":

rawErrorReduction = currentErrorRate - postAIErrorRate
errorRateReduction = MIN(rawErrorReduction * scenario.errorReductionMultiplier, currentErrorRate)
calculatedPostAIErrorRate = currentErrorRate - errorRateReduction

If calculationMethod = "rubric":

adjustedQualityImprovement = MIN(percentQualityImprovement * scenario.errorReductionMultiplier, 100)
errorRateReduction = currentErrorRate * (adjustedQualityImprovement / 100)
calculatedPostAIErrorRate = currentErrorRate - errorRateReduction

Then for both methods:

errorsAvoidedAnnually = errorRateReduction * transactionsPerWeek * 52 / 100
reworkHours = reworkMinutesPerError / 60
qualitySavingsAnnual = errorsAvoidedAnnually * (reworkHours * effectiveHourlyRate + financialCostPerError)

Example (manual method, Base scenario):

rawErrorReduction = 5 - 1 = 4%
errorRateReduction = MIN(4 * 1.0, 5) = 4%
errorsAvoidedAnnually = 4 * 150 * 52 / 100 = 312 errors
reworkHours = 120 / 60 = 2 hours
qualitySavingsAnnual = 312 * (2 * $34.375 + $25) = $29,250
Step 4: Revenue Uplift Benefits
adjustedReallocationPercent = MIN(percentReallocated * scenario.reallocationMultiplier, 100)
hoursReallocatedAnnually = hoursSavedWeekly * 52 * (adjustedReallocationPercent / 100)
revenueSavingsAnnual = hoursReallocatedAnnually * revenueValuePerHour

Example (Base scenario):

adjustedReallocationPercent = MIN(40 * 0.7, 100) = 28%
hoursReallocatedAnnually = 36 * 52 * 0.28 = 524.16 hours
revenueSavingsAnnual = 524.16 * $85 = $44,554
Step 5: Total Benefits and Costs
annualBenefits = timeSavingsAnnual + qualitySavingsAnnual + revenueSavingsAnnual
trainingCosts = employees * trainingHoursPerEmployee * effectiveHourlyRate
annualCosts = (implementationCost + annualSoftwareCost + trainingCosts + changeMgmtCosts) * scenario.costOverrunMultiplier

Example (Base scenario):

annualBenefits = $64,350 + $29,250 + $44,554 = $138,154
trainingCosts = 3 * 8 * $34.375 = $825
annualCosts = (25000 + 12000 + 825 + 5000) * 1.0 = $42,825
4. ROI CALCULATIONS
Annual Run-Rate ROI (Steady-State)
netBenefit = annualBenefits - annualCosts
runRateROI = (netBenefit / annualCosts) * 100

Example: (($138,154 - $42,825) / $42,825) * 100 = 222.6%

Year 1 Actual ROI (With Ramp-Up)
// Step 1: Base ramp factor from months
baseRampFactor = (12 - rampUpMonths + (rampUpMonths / 2)) / 12
// Step 2: Get efficiency percentage (default 100)
baseEfficiency = rampUpEfficiencyPercent (or 100 if not set)
// Step 3: Apply scenario multiplier, cap 20-150%
scenarioAdjustedEfficiency = MAX(20, MIN(150, baseEfficiency * scenario.rampUpEfficiencyMultiplier))
// Step 4: Combine
year1RampFactor = baseRampFactor * (scenarioAdjustedEfficiency / 100)
// Step 5: Calculate Year 1 ROI
year1Benefits = annualBenefits * year1RampFactor
year1NetBenefit = year1Benefits - annualCosts
year1ActualROI = (year1NetBenefit / annualCosts) * 100

Example (6-month ramp-up, 100% efficiency, Base scenario):

baseRampFactor = (12 - 6 + 3) / 12 = 0.75
scenarioAdjustedEfficiency = MAX(20, MIN(150, 100 * 1.0)) = 100
year1RampFactor = 0.75 * 1.0 = 0.75
year1Benefits = $138,154 * 0.75 = $103,616
year1ActualROI = (($103,616 - $42,825) / $42,825) * 100 = 142.0%
Payback Period
paybackMonths = annualCosts / (annualBenefits / 12)

Example: $42,825 / ($138,154 / 12) = $42,825 / $11,513 = 3.7 months

7. MULTI-YEAR PROJECTION RULES
Ramp-Up Business Rules
During ramp-up months: 50% average efficiency
After ramp-up completes: 100% efficiency
Year-by-Year Benefit Multiplier
function calculateYearBenefitMultiplier(year, rampUpMonths) {
  if (rampUpMonths <= 12) {
    // Ramp-up completes within Year 1
    if (year === 1) {
      return (12 - rampUpMonths + (rampUpMonths * 0.5)) / 12;
    }
    return 1.0; // Years 2+ get full benefits
  } else {
    // Ramp-up extends beyond Year 1
    const yearStartMonth = (year - 1) * 12 + 1;
    const yearEndMonth = year * 12;
    
    if (yearStartMonth > rampUpMonths) {
      return 1.0; // Full benefits after ramp-up
    }
    
    const monthsStillRamping = Math.min(12, Math.max(0, rampUpMonths - yearStartMonth + 1));
    const monthsAtFullCapacity = 12 - monthsStillRamping;
    
    if (monthsAtFullCapacity === 0) {
      return 0.5; // Entire year in ramp-up
    }
    
    return (monthsStillRamping * 0.5 + monthsAtFullCapacity * 1.0) / 12;
  }
}

Cost Distribution
Year 1: Implementation + Annual Software + Training + Change Management
Years 2-5: Annual Software only (recurring)
Payback Calculation Logic
If cumulative net benefit turns positive in Year 1: paybackMonths = Year1Costs / (Year1Benefits / 12)
If it turns positive in later years: Use weighted monthly progression
If never positive within 5 years: Report as "Beyond 5 years" (>60 months)
8. EDGE CASES & ROUNDING
Division by zero: Any division by zero returns 0
NaN/Infinity: Invalid numbers are replaced with 0
Percentage capping: All percentages capped at stated bounds (never negative, never above max)
Rounding: Math.round() used for final percentages, no rounding on intermediate calculations
Revenue per hour fallback: If revenueValuePerHour is 0 or not set, falls back to effectiveHourlyRate
