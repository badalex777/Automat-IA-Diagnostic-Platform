Goal
Integrate the full ROI calculation functionality from my separate "ROI Calculator Platform" Replit into this diagnostic platform. The calculator should auto-populate from PIF response data (including rubric assessments) and save results to the existing implementationOpportunities table and matrix.
Current State
This platform (diagnostic) has: Companies → Workflows → Steps, TFA assessments, PIF responses with embedded rubrics, Autopopulated opportunity matrix, opportunity roadmap, report generation, etc. 
Other platform (calculator) has: A complete ROI calculator with multi-year projections, scenario modeling, and Word export functionality(ROI insights per opportunity, Company handbook and operator guide)
Problem: Client employees complete PIF forms which contain all the process data AND rubric assessments, but I (the consultant) have to manually re-enter this data into a separate calculator

Transplant the entire ROI Calculator component from the other platform, including:
Multi-step form (6 steps: Process Info, People & Cost, Time Savings, Quality Impact, Revenue Uplift, Costs & Rampup)
Scenario selector (Conservative, Base, Best, Worst)
Multi-year calculation engine (handles ramp-up periods properly)
Results dashboard with charts
Word export for ROI Insights Report
